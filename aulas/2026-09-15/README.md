# Aula de 15/09/2026

Exemplos de ordenação de vetores em C e C++ com o algoritmo bubble sort.

## Conteúdo da aula

| Tópico | Linguagem | Origem | Conceitos |
| --- | --- | --- | --- |
| [01 — Bubble sort](01-bubble-sort/) | C | Exemplo de aula | Comparação de elementos vizinhos, troca e ordenação crescente |

## Conceitos praticados

- percurso de um vetor com laços aninhados;
- comparação e troca de elementos vizinhos;
- redução das comparações após cada passagem;
- impressão do vetor ordenado.
