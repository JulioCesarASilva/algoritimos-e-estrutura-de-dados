# Bubble sort

Exemplo de ordenação crescente de um vetor de inteiros em C. A função
`bubbleSort` compara elementos vizinhos e os troca quando estão fora de ordem.

## Compilação e execução

Execute os comandos a partir da pasta `c/`:

```bash
gcc -std=c99 main.c -o bubble-sort.bin
./bubble-sort.bin
```

Para o vetor do exemplo, a saída é `11, 12, 22, 25, 34, 64, 90, `.
