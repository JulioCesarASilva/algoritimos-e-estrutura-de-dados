# Aula de 25/08/2026

Estudo de pilhas e de uma fila circular em C, incluindo uma versão interativa
com persistência de dados.

## Conteúdo da aula

| Tópico | C | Origem | Conceitos |
| --- | :---: | --- | --- |
| [01 — Pilha para estudo](01-pilha-estudo/) | Sim | Código apresentado pelo professor | Pilha, operações `push`, `pop` e consulta ao topo |
| [02 — Fila circular](02-fila-circular-exercicio/) | Sim | Código-base e versão melhorada | Fila circular, operações `enqueue`, `dequeue`, consulta à frente e persistência |

## Conceitos praticados

- organização de dados em pilhas e filas;
- controle de estruturas vazias e cheias;
- inserção, remoção e consulta de elementos;
- uso de vetores para armazenar os dados;
- movimentação circular de índices em uma fila.

## Compilação e execução

Cada projeto deve ser compilado a partir de sua pasta `c/`. Os binários são
criados em `tmp/`; a fila melhorada também salva seus dados em `tmp/fila.dat`.
